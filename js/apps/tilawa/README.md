# التلاوة — تطبيقُ العبادة اليوميّة

مصحفٌ يُقرأ ويُستمع إليه، **ويُسمَّع عليه الوردُ فيُمسَك على تاليه**: يجري
المؤشّرُ مع صوته، ويُصطاد انزلاقُه إلى الآية النظيرة فيُرى المفرقَ بعينه،
ويُقيَّد ضعفُه بالزوج فيُعاد عليه. أحدُ تطبيقَي مشكاة — والآخرُ **مشكاةُ
القرآن**، المرجعُ الحاسوبيُّ للبحث والتدبّر (خارطةُ المخرج في
`findings/KHARITAT-ALMAKHRAJ.md`).

**بلا سيرفر**: ملفّاتٌ ثابتةٌ لا غير — لا قاعدةَ بيانات، ولا دالّةَ حراسة، ولا
يخرج من قراءة القارئ شيءٌ إلى خادم.

## التشغيل

```bash
pnpm dev      # ينسخ الأصولَ المشتركة إلى public/ ثمّ يقوم على vite
pnpm build    # tsc --noEmit ثمّ vite build ⇐ dist/
```

**والأصولُ مولَّدةٌ لا مُودَعة**: `public/` كلُّه بالتجاهل، يُملأ في كلّ بناءٍ
من `@mishkat/quran-assets` (نصُّ المصحف والخطوط ودليلُ التلاوات وفروقُ التنزيل)
ومن رزمة المحرّك الحرّ (`public/ort/`) ومن `icons/`.

## الأيقونة

الأصلُ `icons/icon.svg` ونظيرتُها المربّعةُ `icons/icon-maskable.svg` —
**مكتوبتان بأيدينا مسارًا مسارًا**. وما سواهما مشتقٌّ منهما:

```bash
node ../../scripts/make-tilawa-icons.mjs   # ⇐ icons/pwa-{192,512}.png · pwa-maskable-512.png · apple-touch-icon.png
```

فإن بُدّل الرسمُ فأعِد السكربتَ، ولا تُبدَّل نقطيّةٌ بيدٍ.

## النشرُ على Vercel

مشروعٌ مستقلٌّ من هذا المستودع نفسِه، **جذرُه `js/apps/tilawa`**، ونطاقُه
`tilawa.mishkat.qa` (قرارُ المالك ٢٠٢٦-٠٨-١٧). و`vercel.json` ههنا يحمل البناءَ
والمخرجَ والتثبيت على نسق `apps/studio` سواءً بسواء.

## علما البيئة — الجسرُ بين التطبيقين

| العلم | مشروعُه | حاله | ما يفعله |
|---|---|---|---|
| `VITE_TILAWA_LIVE` | **مشكاة** (`apps/studio`) | مطويٌّ | إن كان `1` ظهر زرُّ **«اتلُ»** في أدوات الآية — **يُرفع بعد أوّل نشرةٍ للتلاوة**، لا قبلها، فلا يُعرض بابٌ ميّت |
| `VITE_MISHKAT_LIVE` | **التلاوة** | مرفوعٌ | إن كان `0` طُوي بابُ **«تدبَّرْ في مشكاة»** — ونطاقُ مشكاة قائمٌ حيًّا فلا حاجةَ إليه اليوم |
