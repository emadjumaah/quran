التكليف الكامل في `findings/BAYAN-SESSION-PROMPT.md`.

## المحتويات

- **DESIGN.md** — تصميم الباب: الطبقات الثلاث، نموذج البيانات، حدود ما
  يُدَّعى، تصور الواجهة.
- **SOURCES.md** — جرد المصادر: المحلي الجاهز، والرقمي العام (OpenITI بعد
  انحجاب الشاملة عن الجلب الآلي)، والمحفوظ الحقوق، وترتيب الأولوية.
- **PROPOSAL.md** — العرض على المالك: المراحل والأحجام والبوابات والقرارات
  الستة المطلوبة.
- **cards/** — خمس بطاقات تجريبية مكتملة يدويًّا (إثبات الجدوى):
  1. أتى / جاء
  2. خوف / خشية (مع طبقة تحشية يدوية موسومة)
  3. اسطاعوا / استطاعوا (الكهف ٩٧)
  4. القاسطون / المقسطون
  5. بصائر
- **queries/usage_map.py** — سكربت خريطة الاستعمال الحتمي (مدخله مواصفة
  البطاقة، مخرجه خريطة كاملة موضعًا موضعًا).
- **maps/** — الخرائط المولدة للبطاقات الخمس (ناتج السكربت كما هو).

## حالة القسم المنشورة (2026-07-23)

| الطبقة | ما استقر |
|---|---|
| بطاقات محرَّرة | ٢٠ بطاقةً بخرائط محسوبة وقراءاتٍ منسوبة |
| بطاقات آلية | ٤٣٢ بطاقةً (بعد تنظيف علامات الرقمنة وحذف المكرر)، مزمَّرةً بالحقول الدلالية المحسوبة |
| مكتبة البيان | **تسعة كتب · ٣٠٦٩ مدخلًا** بثلاث عائلات: المداخل بالحرف (الفروق، البصائر، الوجوه، النزهة، الدامغاني) · المتشابه بالسورة (درة التنزيل، ملاك التأويل) · علوم القرآن بالأنواع (البرهان، الإتقان) |
| فهرس المطروق | `public/bayan-tariq.json` — ١٣٢٧ جذرًا و٤٩٩٥ موضعًا: أين طَرَق العلماءُ هذا في متوننا المفهرسة (نصف آلية «جبهة غير المطروق» — §٦ في BAYAN-METHODOLOGY) |
| الجسور | كل بطاقةٍ تُذيَّل بـ«أين طُرق هذا عند العلماء» (جذورها ← كتب المداخل، ومواضعها ← كتب المتشابه والأنواع)؛ وبطاقةُ الآية تحمل لوحة «في كتب البيان» |
| الأداء | دليل رؤوسٍ خفيف (٣٧٥ ك.ب) للبحث الفوري، ونصُّ المدخل يُجلب عند فتحه، وبحثٌ عميقٌ في المتون بزرٍّ اختياري |
